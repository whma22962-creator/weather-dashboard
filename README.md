# 🌤️ 中文天气仪表盘

一个功能完整的中文天气查询 Web 应用，采用现代化卡片式布局，支持浅色/深色模式切换。

## ✨ 功能特性

- ✅ **城市天气查询** - 支持输入城市名称实时查询天气
- ✅ **当前天气显示** - 温度、体感温度、湿度、风速、气压等详细信息
- ✅ **7天天气预报** - 展示未来一周的天气趋势
- ✅ **浅色/深色模式** - 支持主题切换，自动保存偏好设置
- ✅ **响应式设计** - 完美适配电脑、平板和手机
- ✅ **无需 API 密钥** - 采用 Open-Meteo 免费 API，无前端密钥暴露风险
- ✅ **加载状态** - 友好的加载动画和消息提示
- ✅ **错误处理** - 城市不存在、网络错误等提示

## 🔧 技术栈

- **前端框架**: 纯 HTML5、CSS3、JavaScript（无框架依赖）
- **天气数据**: Open-Meteo API（完全免费，无需密钥）
- **样式系统**: CSS 变量 + 响应式栅格布局
- **状态管理**: LocalStorage（主题偏好保存）

## 📍 使用的 API

### Open-Meteo

**为什么选择 Open-Meteo？**

1. **完全免费** - 无需注册、无需 API 密钥
2. **无速率限制** - 支持前端直接调用
3. **CORS 启用** - 跨域请求无障碍
4. **数据准确** - 基于多个全球气象数据源
5. **功能完整** - 提供当前天气、预报、历史数据等
6. **全球 CDN** - 响应快速稳定

**API 端点：**

- **地理编码 API**: `https://geocoding-api.open-meteo.com/v1/search`
  - 将城市名称转换为地理坐标

- **天气预报 API**: `https://api.open-meteo.com/v1/forecast`
  - 获取当前天气和7天预报

## 🚀 快速开始

### 方式一：在线预览

1. 在浏览器中打开 `index.html` 文件
2. 或直接访问项目 GitHub Pages（如已启用）

### 方式二：本地运行

```bash
# 克隆仓库
git clone https://github.com/whma22962-creator/weather-dashboard.git

# 进入项目目录
cd weather-dashboard

# 使用任意 HTTP 服务器运行
# 方式1：Python
python -m http.server 8000

# 方式2：Node.js (如已安装 http-server)
npx http-server

# 方式3：直接打开 index.html 文件
```

然后在浏览器中访问 `http://localhost:8000`

## 📝 使用说明

1. **查询天气**
   - 在输入框中输入城市名称（如：北京、上海、纽约等）
   - 按回车键或点击搜索按钮
   - 等待加载完成显示结果

2. **查看详情**
   - 当前卡片显示实时天气数据
   - 预报卡片显示未来 7 天的天气趋势

3. **主题切换**
   - 点击右上角的 🌙/☀️ 按钮切换主题
   - 偏好设置自动保存到本地

## 🐛 已知限制

- 仅支持中文城市名称查询
- 天气预报数据来自 Open-Meteo，精度取决于其数据源
- 某些小城镇可能无法查询

## 🔄 数据更新

- 每次查询时实时获取数据
- 无缓存机制，总是显示最新数据
- 建议查询间隔不少于 10 分钟
